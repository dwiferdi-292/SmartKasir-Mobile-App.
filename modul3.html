D. Kelas Output (Oracle)

• Output 1 (Sukses): Transaksi berhasil diproses, stok inventaris berkurang, struk belanja dicetak, dan uang kembalian dihitung akurat (Kembalian = C - T).
• Output 2 (Tolak Uang Kurang): Transaksi ditolak dengan notifikasi error "Uang diterima kurang dari total bayar!" (jika C < T).
• Output 3 (Tolak Kuantitas Invalid): Penambahan kuantitas dibatasi maksimal pada angka sisa stok fisik toko.

Incident ID: INC-SK-001  |  Tanggal: 2026-10-21  |  Pelapor: MUCHAMMAD DWI FERDI ILHAM ARIFIN

Test Basis & Environment: RQ-002, PHP 8.2 / Chrome 129, Web live https://smartkasir.infinityfreeapp.com/

Summary: Notifikasi sukses pendaftaran akun baru pada form registrasi diarahkan dengan styling alert error berwarna merah.

Steps to Reproduce:
1. Buka halaman registrasi register.php.
2. Masukkan nama, email baru, password, dan pilih peran Kasir.
3. Klik tombol "Daftar Akun Baru".
4. Amati pesan notifikasi pada halaman login index.php.

Expected Result: Muncul pesan sukses berwarna hijau (alert success) dengan ikon centang.

Actual Result: Muncul kotak berwarna merah dengan pesan "Registrasi berhasil! Silakan login." yang menyerupai pesan kegagalan login.

Severity: Minor (kosmetik UI / UX feedback).

Status & Tindakan: RESOLVED (Closed). Kode di register.php telah diganti menggunakan parameter ?success= dan index.php telah ditambahkan elemen .alert.success hijau.
